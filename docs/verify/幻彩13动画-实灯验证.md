# 幻彩灯 13 个动画 · 实灯验证

对象：`apps/user_app/ws2812-fx-lib/WS2812FX_C/ws2812fx_effect.c` 末尾的 13 个动画，
以及 `apps/user_app/led_strip/led_strand_effect.c` 里的模式映射。
规格：`样机信号采集/AI-动画总规格.md`。

## 前置

- 实灯为单路 PA8、16 颗 WS2812，逻辑索引 0 是 RGB PWM 占位，动画只写 1~16。
- 亮度固定走工程既有链路（`fc_effect.b` 预乘），所以出线值约为规格值的 44%，属预期。
- 速度档 100（默认）对应规格节拍；速度档越大越慢。

## 验证步骤

1. 连按 UART `0x05/0x07` 或 433「幻彩效果切换」13 次，确认画面依次为
   橙填充 → 品红堆积 → 绿阶梯 → 橙点 → 白蓝白 → 七彩块 → 白光 →
   多彩呼吸 → 蓝紫呼吸 → 白呼吸 → 多彩渐变 → 多彩跳变 → 多彩渐变流水，
   第 14/15 次进入两个声控模式，第 16 次回到第 1 个画面。
2. 用秒表量三个周期：00 约 0.79 s，07 约 9.33 s（红→白一轮），11 约 2.60 s；误差应在 ±5% 内。
3. 从 06 白光切到 07/08/09/10 时，应先看到画面在约 0.2 s 内暗下去再起呼吸；
   切到 00~06、11、12 时应直接硬切，没有暗场。
